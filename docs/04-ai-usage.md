# 04 AI 使用说明

## AI 辅助内容（如实记录）

本项目由 AI 编程助手根据作业要求搭建，包括 Python 实现、合成素材、脚本化 Mock、测试、CLI、Trace、示例生成脚本和文档初稿。助手在当前环境运行了 pytest、离线场景与 DeepSeek Pro 真实 API 场景。

真实模型只负责结构化动作决策；search/generate/estimate/save 都是本地 Mock 工具，脚本文字不是 DeepSeek 撰写的生产文案。Mock 模型的分支逻辑仅用于流程验收。

## 验证方式

测试覆盖费用求和、failed 状态、幂等、缺输入零调用、依赖拒绝、预算/时间硬护栏、非法动作修正、调用上限与断点恢复。示例由运行脚本或实际 CLI 生成；验收文档引用原始文件。证据审计脚本核对状态、Trace 和保存费用。未手写成功日志，也不记录模型内部思维过程。

本次实现中遇到默认 Python 不可用、沙箱临时目录权限、测试依赖网络访问和 Windows 硬链接限制；实际改用可用解释器、工作区测试目录及平台适配的原子保存，并重新测试。没有因此虚构测试成功。
